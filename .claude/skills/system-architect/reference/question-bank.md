# System Architect 关键问题库

## 目标与用户
- 主要用户是谁，核心任务是什么
- 成功标准是什么，用哪些指标衡量
- 失败标准是什么，什么情况算不可接受

## 规模与约束
- 预计 DAU QPS 数据量 增长曲线
- 延迟目标与可用性目标
- 成本上限或成本偏好
- 时间节点与人力结构

## 数据与合规
- 是否涉及个人敏感信息
- 数据存储地域与合规要求
- 数据保留与删除要求

## 可靠性与发布
- 是否需要灰度
- 允许的宕机窗口
- 回滚要求与最大回滚时间

## 依赖与集成
- 必须集成哪些系统
- 哪些依赖不稳定或不可控
- 需要哪些鉴权与权限模型

## 团队与维护
- 团队熟悉哪些技术栈
- 谁负责长期运维
- 是否需要可插拔与多租户
