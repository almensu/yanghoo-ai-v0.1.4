# PRD 关键问题库

## A 问题与用户
- 这次要解决的核心问题是什么
- 主要用户是谁，谁会直接受益
- 用户现在的替代方案是什么，哪里最难受
- 典型路径是什么，从触发到完成

## B 范围与优先级
- 这次必须交付的最小闭环是什么
- 哪些需求是加分项，可以延期
- 绝对不做的是什么

## C 成功指标
- 这次成功怎么衡量，用哪些指标
- 指标口径是什么，谁看板，多久复盘
- 现在的基线是多少

## D 约束与依赖
- 截止时间与里程碑
- 依赖哪些系统与团队
- 是否有合规，隐私，权限要求

## E 上线与风险
- 是否需要灰度，灰度人群怎么选
- 最坏情况是什么，怎么回滚
- 需要哪些监控与告警
