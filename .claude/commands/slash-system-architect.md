# System Architect

Invoke the system-architect skill to design practical system architectures from messy requirements.

## Usage

Use this command when you need to:
- Design system architectures from requirements
- Create technical solutions for complex problems
- Plan microservices architecture
- Design data flows and API structures
- Define deployment and scaling strategies
- Create security boundaries and SLOs

## Examples

- `/slash-system-architect` - Launch with interactive prompt
- `/slash-system-architect e-commerce platform` - Design architecture for e-commerce
- `/slash-system-architect microservices migration` - Plan microservices transition
- `/slash-system-architect real-time analytics` - Design streaming data architecture

The system-architect skill will produce comprehensive architecture documentation including:
- Clear goals and constraints
- Component design and APIs
- Data flows and deployment patterns
- SLOs, security, and risks
- Rollout plans and ADRs
