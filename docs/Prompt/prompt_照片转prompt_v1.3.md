## 风险与缓解

- 层级顺序与可见性混乱 → 严格“前到后”排序，并在每层标注遮挡关系。  

- 人物服装细节主观猜测 → 仅据可视证据；其余入“不可判定”。  

- 左右视角混淆 → 环境用观者视角；服装细节用人物自身视角并标注。  

- 多人信息混杂 → 统一人物编号（S1/S2…），逐人逐件输出。  

- **比例归类错误** → 同时输出数值比、归类、偏差%，若超阈值则“自定义+最简分数”。
