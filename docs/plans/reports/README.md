# Reports

Gemini writes implementation reports here after each stage.

## Naming

Use:

```text
YYYY-MM-DD-stage-N-short-title-report.md
```

Example:

```text
2026-04-26-stage-1-apps-packages-skeleton-migration-report.md
```

## Required Content

Each report must include:

- stage name
- changed files
- implementation summary
- verification commands and output summary
- skipped checks with reasons
- unresolved risks
- suggested next task

Codex reviews reports before assigning the next stage.
